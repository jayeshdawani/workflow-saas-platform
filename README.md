# Workflow SaaS Platform

A multi-tenant workflow and task management SaaS for student organizations, campus teams, and small nonprofit groups.

## Problem
Small teams often manage tasks, members, and project updates across scattered tools.

## Target Users
- Student organizations
- Campus clubs
- Small nonprofit teams

## Core Features
- Organizations/workspaces
- Members and roles
- Projects
- Tasks
- Comments
- Activity logs
- Dashboard

## Tech Stack
- Python
- FastAPI
- PostgreSQL
- React
- TypeScript
- TailwindCSS
- Docker

## Current Status
Week 1 setup in progress.

## Roadmap
- Week 1: Project setup and backend foundation
- Week 2: Auth, organizations, and dashboard
- Week 3: Projects, tasks, RBAC, and tenant isolation
